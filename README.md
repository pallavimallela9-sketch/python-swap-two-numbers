# Swap Two Numbers

## Description

This Python program swaps the values of two numbers without using a third temporary variable.

Python's multiple assignment feature is used to exchange the values directly.

## Concepts Used

* Variables
* User Input
* Type Conversion
* Multiple Assignment
* Tuple Unpacking
* Functions
* Exception Handling

## Technologies

* Python 3

## How to Run

```bash
python swap_two_numbers.py
```

## Sample Output

```text
================================
       SWAP TWO NUMBERS
================================
Enter first number: 25
Enter second number: 50

Before Swapping:
First Number  : 25
Second Number : 50

After Swapping:
First Number  : 50
Second Number : 25
```
